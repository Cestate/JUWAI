# 句外 JUWAI MVP

这是一个可直接打开或静态部署的轻量化 Web App，覆盖比赛 Demo 所需的核心闭环：

`首页 -> 文字/图片输入 -> 6 句推荐 -> 复制/收藏 -> 生成卡片`

当前界面已按 `句外-分享版.html` 概念稿迁移为移动端优先的“鼠尾草诗页”风格：米白背景、鼠尾草绿强调色、诗页式排版、首页入口卡片与底部四栏导航。概念稿仅作为视觉参考，不包含账号、社区等超出 MVP 的功能。

## 本地运行

仓库没有构建步骤，直接启动静态服务器即可：

```powershell
python -m http.server 4173
```

然后访问 <http://localhost:4173/>。

也可以直接双击 `index.html` 使用。使用本地服务器时，图片预览和浏览器下载行为更稳定。

## 当前 MVP 边界

- 游客直接使用，不需要登录或注册。
- 收藏使用 `localStorage`，仅保存在当前浏览器。
- 当前内置的是可离线演示的本地场景理解与句子数据，覆盖旅行、毕业、心动、低能量和日常等场景。
- 所有结果标记为“AI 原创”，没有伪造作者、作品或出处。
- 内容分类统一由 `CONTENT_TAXONOMY` 管理，包含内容类型、情绪和场景三组稳定枚举。
- 图片用于演示“上传并理解场景”的入口；真正接入 Vision 模型时，将 `app.js` 中的 `createResults()` 替换为 API 请求即可。
- 登录、探索搜索、分类收藏夹、历史记录、社区和推荐算法不在本版本范围内。

## 接入真实 AI

建议新增一个后端接口，例如 `POST /api/understand`，请求包含：

```json
{
  "text": "用户描述",
  "image": "multipart/form-data 或对象存储 URL",
  "tone": "克制"
}
```

接口返回 `scene`、`emotion`、`tags` 和 6 条句子。不要把模型密钥放进前端；前端只负责提交输入、展示生成状态和渲染结果。

更完整的字段约定、版权规则和 RAG 扩展方式见 [docs/DEVELOPER.md](docs/DEVELOPER.md)。
